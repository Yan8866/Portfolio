Projects Trading Strategy Evaluation (Python)

This project evaluates stock trading strategies using three technical indicators: B%, PPO, and Stochastic Oscillator. Manual Strategy and Strategy Learner based on Random Forest classification are compared against a benchmark using in-sample and out-of-sample data. Results show that while both strategies outperform the benchmark in-sample, the Manual Strategy continues to perform well out-of-sample, whereas the Strategy Learner struggles with unseen data and is negatively impacted by trading costs.

Churn and Diabetes Prediction using KNN, ANN and SVM (Python)

This project compares their performances and examines the impact of data dimensionality and size. Results show that ANN performs best overall with moderate computational cost, SVM is effective but computationally expensive, and KNN struggles due to the curse of dimensionality, challenging the assumption that larger datasets always lead to better model performance.

Document Summarizer-SUMA

SUMA is an AI-powered document summarization and question-answering web app using Gradio and the OpenAI API. The app allows users to upload .pdf, .txt, or .docx files and get concise summaries or intelligent answers. It is deployed on an AWS EC2 instance. The OpenAI API key is securely stored in AWS Secrets Manager and an IAM Role is configured for the EC2 instance to access it safely. The environment setup is automated. The app is lunched via systemd for 24/7 uptime. The service is open to the public through EC2’s Elastic IP.

Reinforcement Learning Projects

I implemented a PPO-based reinforcement learning agent in PyTorch to solve the LunarLanderContinuous-v3 environment with continuous control. By tuning key hyperparameters—especially the value optimizer learning rate—I improved training stability and performance, with the best model achieving an average return of about 260 over 100 consecutive evaluation runs. The learned policy consistently exceeded the 200-point success threshold and demonstrated stable, reliable landings with minimal performance degradation across episodes.
