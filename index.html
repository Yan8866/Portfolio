Computer Vision Projects

Kalman Filter Tracking

I implemented a constant-velocity Kalman Filter that predicts and corrects object positions using noisy template-matching measurements, producing smoothed estimates of each target’s center. For multi-object tracking, I instantiated one independent Kalman Filter per person, each initialized at its own bounding-box center and updated separately using its own template and measurement stream. The tracking loop activates and deactivates filters based on each target’s start and end frame, allowing all trackers to run simultaneously and maintain stable position estimates even when measurements become noisy or intermittent.

Particle Filter Tracking

I implemented a particle filter that represents each object’s position using a cloud of weighted particles, which are predicted with Gaussian motion noise and then reweighted based on how well their local image patch matches the template. After normalizing weights, I resample particles to focus the distribution around high-likelihood regions and compute a weighted mean and spread to estimate and visualize the object’s position. Using this filter inside a multi-object tracking loop, each target is tracked independently by its own particle distribution, allowing robust tracking even under noise, partial occlusion, and rapid motion.
